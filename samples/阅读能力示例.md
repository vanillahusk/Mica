# 安静地读，清楚地看

这是一份 Mica 阅读能力示例。右侧目录可以定位章节；打开图表后，用滚轮缩放、鼠标拖动平移，或点击 **全屏 / 新窗口**。

> [!TIP]
> 阅读时保持正文干净，需要时再打开书架、目录和图表工具。

## 从文字到图表

```mermaid
flowchart LR
    A[打开 Markdown] --> B[后台解析]
    B --> C[先显示正文]
    C --> D{阅读到哪里？}
    D --> E[按需绘制图表]
    D --> F[按需显示公式]
```

```mermaid
sequenceDiagram
    participant Reader as 读者
    participant Mica as Mica
    Reader->>Mica: 打开本地文档
    Mica-->>Reader: 显示正文与目录
    Reader->>Mica: 点击图表
    Mica-->>Reader: 缩放、平移、全屏查看
```

## 代码需要清晰的颜色

```java
public class Reader {
    // 让内容成为主角
    private final String name = "Mica";

    public String welcome() {
        return "Keep reading.";
    }
}
```

行内代码 `String name = "Mica"` 与正文区分，但不过分抢眼。

## 常见 Markdown 内容

| 能力 | 状态 | 操作 |

| 代码复制 | 支持 | 点击复制代码 |

- [x] ~~删除线~~、==高亮==、H~2~O、x^2^
- [x] 引用链接与脚注[^reading]

   - 查看代码与示意图

Markdown
