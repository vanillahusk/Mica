# Mica

一个轻量的 Windows Markdown 与 ChatGPT 对话阅读器，包含自有的 Mica Sync 浏览器扩展。

## 阅读能力

- 以正文为中心，提供暖灰、纸白、米杏、深海四套主题；书架、目录和编辑功能按需展开。
- 顶部 **Aa → 主题** 即时切换，自动记住选择；正文、代码、图表与原生界面同步换色，不重排正文。
- 长文滚动条宽 18px，滑块最小高度 56px；阅读和编辑共用跟手拖动，拖动期间即使文档高度变化也保持鼠标位置。正文使用真实排版高度，图表/公式/高亮仍按需加载。
- 阅读位置以“源码段落 + 段内距离”为主、像素偏移为兼容回退；切换文档和关闭时保存，重启、调整字号、改变窗口宽度或开关侧栏后尽量保持在原句。最多保留最近 200 篇，不在滚动过程中持续写盘。
- 打开、编辑和保存 `.md`、`.markdown`、`.txt` 文件。
- 打开本地文件夹，在侧边栏快速切换文档。
- 阅读、编辑、分栏预览三种模式，支持拖入本地文件。
- 面向中文长文优化的排版系统，支持标题、列表、任务项、引用、表格、链接与行内代码。
- 顶部“查找”提供命中数、上一处/下一处和当前命中强调；目录支持标题筛选，点击目录后目标段落会短暂强调。
- 代码块提供语法高亮、文本选择、横向滚动和一键复制。
- 流程图采用 beautiful-mermaid 1.1.3 的 ELK 布局与 SVG 渲染，其他图表保留 Merman。四主题统一配色；支持滚轮缩放、拖动平移、适应窗口、实际大小、全屏和独立窗口。
- 默认在 Worker 中绘图，支持 8 秒超时和切换取消。绘图失败时可手动选择 Mermaid 12 兼容路径；不会静默切回主线程。流程图先验证语法，交互布局限制为 200 条边。
- 图表使用稳定高度的预览，延迟绘图不会突然推走下方正文；大图点击“查看图表”查看完整细节。
- KaTeX 行内/块级公式，支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`。
- 脚注、引用式链接、任务列表、定义列表、提示块、删除线、高亮、上下标和 HTML 折叠区。
- 相对路径图片与图片放大；本地图片只允许读取当前文档目录及其子目录，不越界读取文件。
- 后台解析、分帧插入、视口附近按需渲染图表/公式/代码高亮，以及有界内存缓存。
- 从浏览器扩展一键同步 ChatGPT 会话；数据只保存到本机。
- 会话按消息 ID 增量合并，仅在点击“同步到 Mica”时落盘，避免后台频繁写入。

## 阅读、编辑与笔记

- 顶部 **阅读 / 编辑** 直接切换。编辑默认在排版后的正文中进行：标题、粗体、引用、列表实时呈现，光标所在行显示相应 Markdown 标记；格式工具栏提供鼠标操作和撤销重做。保存仍需点击顶部 **保存**。
- 非活动代码块、表格、Mermaid 和块公式显示预览，点击块上的 **编辑** 原位修改语法；离开后重新呈现。行内公式与图片也支持预览。表格单元格富文本编辑、任意 HTML 所见即所得和 Typora 全部语法并未实现；高级操作可使用 **··· → 高级：源码分栏**。
- 编辑时可直接点击表格预览中的单元格，定位并选中对应 Markdown 单元格内容；阅读时表格可在独立查看器中展开并适应宽度。
- 实时编辑按视口加载，编辑组件仅在首次编辑时加载；Markdown 文本始终是数据源，不通过富文本 DOM 反向转换原文。阅读与编辑使用源码行映射尽量保持段落位置。
- 拖选保持代码/图表预览和布局稳定，不随选区反复展开源码；输入只发送修改状态，保存和切换时获取完整快照。中文组词未确认时会提示先完成输入。
- 选区使用原生文本高亮，四主题分别设置选区底色和文字色，引用/代码底色不会覆盖选区。字号改变时同步刷新编辑器几何信息，避免行尾选中下一行；详见 [0.7.2 交互修复与参考](docs/interaction-fixes-0.7.2.md)。
- ChatGPT 同步原件只读，需要编辑时使用 **··· → 另存为 Markdown…**。
- 阅读时选中文字，会出现 **高亮 / 笔记 / 标签 / 复制** 浮条。高亮立即保存；笔记与标签在右侧填写后点击 **保存笔记**。普通选区不会自动保存为高亮。
- 顶部 **笔记** 展开本篇笔记；**＋ 新建** 记录不绑定选区的全文想法。卡片显示摘录、想法、时间和可点击筛选的标签；进入单条笔记后使用独立编辑页，点击 **全部笔记** 返回列表，未保存内容保留为草稿。阅读、编辑和分栏时均可记笔记，目录与笔记共用右栏。
- 可筛选摘录、笔记内容或 `#标签`，点击笔记/定位返回原文；支持导出本篇笔记为 Markdown（导出包含当前草稿）。标签使用空格或逗号分隔。
- 笔记独立保存在 `%LOCALAPPDATA%\Mica\notes`，不会写入原 Markdown 或同步会话。只在保存/高亮/删除时写单条文件，删除记录保留恢复数据，多窗口旧版本保存会提示冲突。
- 未保存笔记可跨文档切换保留，关闭窗口会提醒，但尚未保存的草稿不会跨程序重启保留。
- 摘录结合文字与上下文重新定位；文字被删、重复段落无法区分时不猜测位置，笔记仍保留。笔记按本地文件完整路径或会话 ID 关联，移动/重命名文件暂不自动迁移笔记。
- 当前支持正文和代码文字摘录（最多 8,000 字符），图表、公式内部标签暂不支持摘录。

设计参考和取舍见 [阅读笔记设计](docs/reading-notes-design.md)。

## 下载

在 [GitHub Releases](https://github.com/vanillahusk/Mica/releases) 下载 `Mica-*-win-x64.zip`。这是免安装的原生 Windows x64 版本，解压后直接运行 `Mica.exe`，不需要 .NET Desktop Runtime；系统仍需 WebView2。配套的 `Mica-Sync-*-chrome.zip` 是浏览器扩展，解压后通过浏览器的“加载已解压的扩展”使用。

主分支的每次构建也会保留两个压缩包作为 Actions Artifact；版本号首次出现时，流水线会自动创建对应的 GitHub Release。

## 构建原生发行版

应用图标的可编辑源文件为 `Assets/mica.svg`。修改后运行 `./scripts/build-icon.ps1` 生成多尺寸 `mica.ico` 与预览 `mica.png`；ICO 嵌入程序文件和窗口资源，支持任务栏及 Windows 文件关联图标。

官方发行版使用 Go + Wails 外壳，开发需要 Windows 10/11、Go 和 Node.js 24；运行用户不需要 Go、Node.js 或 .NET。阅读器使用系统 WebView2 Runtime，不携带 Chromium。

```powershell
cd Native
node build.mjs
go mod download
go test ./...
node native-build.mjs
```

原生资源已经嵌入 `Native/Mica.exe`，可以单文件运行。根目录的 WPF 工程只作为旧版兼容实现保留，不进入官方发行包。打开 `samples/阅读能力示例.md` 可体验公式与图表；方案与研究来源见 [渲染优化记录](docs/reader-research.md)。

## 从资源管理器打开

### 安装和更新（推荐）

解压完整发布包，双击其中的 `Install-Mica.cmd`。首次默认安装到发布目录旁的 `Mica\app\Mica.exe`，不默认安装到 C 盘；也可以运行 `Install-Mica.ps1 -InstallRoot "D:\你的目录\Mica"` 指定位置。安装目录记录在 `HKCU\Software\Mica\InstallDirectory`，以后更新自动沿用此位置。桌面与开始菜单快捷方式也指向该固定目录，不再直接使用版本目录内的程序作为默认应用。

安装脚本验证完整文件后再替换程序，保留旧程序和入口配置备份；拒绝降级或覆盖正在运行的正式版，不会强制关闭窗口。若提示正在运行，保存编辑并关闭 Mica 后重试。会话与偏好仍保存在 `%LOCALAPPDATA%\Mica`，安装过程不修改它们。已有 ChatGPT 连接会自动迁移，仅更新主机路径，保留已授权的扩展来源。

首次安装后，在 Windows 设置中选择 Mica 为 `.md` / `.markdown` 默认应用。升级只修复 Mica 自己的注册路径，不修改 Windows 的 `UserChoice`。默认应用、快捷方式和同步入口从此使用固定路径。

### 便携运行

Mica 支持 `Mica.exe "D:\文档\笔记.md"`，也支持 `--file` 参数。中文、空格路径和 `.markdown` 文件均可直接打开，不必先进入首页。应用已经运行时，再双击文件会在新窗口打开。

将**整个发布目录**放在固定位置后，点击顶部 **··· → 默认打开 Markdown…**，在 Windows 默认应用设置中将 `.md`、`.markdown` 选为 Mica。也可以右键文件 → 打开方式 → 选择其他应用 → 浏览到 `Mica.exe` → 始终使用。程序只注册候选应用，不会强制覆盖现有默认应用。移动程序后需要重新设置。

主题偏好保存在 `%LOCALAPPDATA%\Mica\preferences.json`，只在选择变化时写入；不修改文档。

## 连接浏览器扩展

浏览器扩展源码位于 [`BrowserExtension`](BrowserExtension)。它可读取 ChatGPT 完整原始会话、同步到本机 Mica，并为网页尚未加载的历史消息打开独立阅读页后精确定位。扩展阅读页只使用本地快照，不依赖云端服务；构建与安装说明见 [`BrowserExtension/README.md`](BrowserExtension/README.md)。

最简单的方法是在 Mica 首页点击 **连接 ChatGPT**：

1. 打开 `chrome://extensions` 并开启开发者模式。
2. 找到 LightSession，复制其扩展 ID。
3. 粘贴到 Mica 的连接窗口，点击 **完成连接**。
4. 重新加载扩展，进入任意 ChatGPT 对话。
5. 点击对话右侧目录中的 **同步到 Mica**。

使用上述安装脚本更新时会自动迁移现有连接，无需重新填写扩展 ID。仅便携运行且尚未正式安装时，移动发布目录后才需要重新连接。已安装时，新版便携程序的关联设置也优先使用固定安装入口。

开发阶段也可以用脚本注册。先执行发布命令，然后运行：

```powershell
.\scripts\install-native-host.ps1 -ExtensionId 你的扩展ID
```

同步文件位于 `%LOCALAPPDATA%\Mica\conversations`。卸载注册：

```powershell
.\scripts\uninstall-native-host.ps1
```

## 数据与安全

Native Messaging 主机只接受已注册扩展的消息，协议只包含会话标题、来源地址和消息内容；不会启动网络服务，也不会上传本地文档。会话文件采用临时文件替换写入，避免异常退出产生半写入文件。Markdown HTML 经清理，不执行文档脚本；公式关闭可信命令，Mermaid 使用 strict 安全模式。文档自身引用的 HTTPS 图片会向图片地址发起请求；渲染引擎本身不使用 CDN。
