# Mica Sync

Mica 自有的轻量浏览器扩展，负责把当前 ChatGPT 对话按 Markdown 同步到本机 Mica，并在弹窗中保留本地历史入口。点击历史项会返回对应的 ChatGPT 页面。没有云端服务、账号和遥测。

0.2.1 在原始会话分页读取的基础上迁入 light-session-fork 独立阅读页（MIT，见 THIRD-PARTY-NOTICES.txt）。点击提问时，网页已加载的消息直接定位；未加载的历史消息自动在新标签页打开完整会话，并定位到对应提问，不必向上滚动加载，也不要求先启动桌面端。“在新页阅读”可随时打开阅读页，支持提问目录、搜索、复制、阅读位置记忆和 Markdown 导出。阅读快照仅存于本机扩展存储。浏览器阅读页将 Mermaid 显示为代码；图形渲染仍在 Mica 桌面端。

完整同步需要已保存的 /c/ 对话及有效登录状态。接口失败时会显示原因，不会把部分 DOM 内容报为完整同步成功。“同步可见内容”是单独的手动回退入口。会话登录请求头只在网页内存中使用，不保存到扩展或桌面端。

升级：保留同一个扩展 ID，重新加载本扩展并刷新 ChatGPT 标签页（原始读取桥接在页面加载时启动）。在 Mica 0.9.14 中连接一次，使本机同步路径指向新版可执行文件。旧插件自己的私有历史存储不会自动迁移。

## 安装

1. 打开 `chrome://extensions`，启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择本目录。
3. 点击扩展图标，复制扩展 ID。
4. 在 Mica 中选择“连接 ChatGPT”，粘贴 ID 并完成连接。
5. 刷新已打开的 ChatGPT 页面，在网页右下角或扩展弹窗中点击“同步到 Mica”。

从 0.1.2 起扩展 ID 已固定。首次升级到 0.1.2 时请在 Mica 中重新连接一次；后续版本即使换了解压目录，也会保持同一个扩展 ID。

同步会保留 Markdown 标题、段落、列表、粗体、链接、内联代码以及带语言的代码块；Mermaid 会以 `mermaid` 围栏传入 Mica。
