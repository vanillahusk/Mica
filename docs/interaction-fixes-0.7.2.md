# 0.7.2：先修交互，再谈引擎

## 复现与修复

- **行尾点不到**：修改根元素字号 CSS 变量后，CodeMirror 高度模型仍保留旧行高。125% 时，画面句号位于源码 25–26，`posAtCoords` 却返回下一行的 27。仅 `requestMeasure()` 不足以使字体模型失效。现在用公开的 Compartment/theme 重配置通知字体变化，更新测量；没有改 CodeMirror 私有字段，也不重新创建编辑器或丢弃撤销栈。
- **引用选区消失**：旧 `drawSelection` 位于内容背景下方，引用和代码块的不透明底色遮住它。现在使用原生文本选择，不再单独绘制选区；暖灰、纸白、米杏、深海都有独立的选区前景和背景色。此应用采用单光标编辑，不需要多选区图层。
- **拖动不跟手**：移除正文 `content-visibility:auto` 的估算块高度。仍在帧预算内分批挂载文字，但挂载的文字直接取得真实布局；图表、公式和语法高亮保持视口附近按需处理。阅读和编辑共用自定义滚动条，pointer capture 保持拖动；持有鼠标期间固定抓取点、按当前 scrollHeight 持续映射文档比例，避免虚拟化、图片或字号变化使滑块脱手。用户开始拖动后，异步加载完成不再强行恢复旧阅读偏移。
- **图表可读性**：标准 Mermaid 与隔离引擎共用图表配置；节点、边线和文字不再使用低对比的 UI 辅助文字色。四主题分别配色，调整节点间距、实体边距和标签宽度，长英文实体名不再在中间任意断行。保持安全 SVG、缩放、全屏、独立窗口和默认标准 Mermaid；隔离引擎仍是可选实验模式，布局并不承诺与标准 Mermaid 完全相同。

## 验证

- 句号命中：真实 DOM Range 字形坐标 + 鼠标按下/移动/抬起；窗口宽 1120/700，字号 100%/125%/150%。修改前可复现下一行误选，修改后通过。
- 四主题引用选区：原生选中文字核对；各主题选区文字/背景对比度至少 4.5:1；实际截图人工检查。
- 长文拖动：449,521 字符混合标题、长短段落、代码块；阅读和编辑各在 15%、50%、85%、32%、70% 往返，并在拖动中改变字号。滑块与鼠标误差小于 2px，文档位置比例误差小于 0.8%。
- 两种图表引擎：中文、时序、类、ER、状态、思维导图等原有测试；新增 PROMPT_OPTIMIZATION_PROFILE 等长实体名的完整性和不拆行检查。
- 保留格式按钮、撤销重做、CRLF、中文 composition 保护、笔记、缓存、取消、离线安全等回归。

正文真实排版是一个明确取舍：本机自动化中，169,200 字符文档首屏约 71ms、全部文字挂载约 442ms；比先前估算高度的全部挂载更慢，但不再把重新排版的高度变化留给用户拖动时承担。45 万字符另一种块分布样本约 357ms，不能据字符数直接比较性能。计时不包含所有按需图表，不是程序冷启动或真实屏幕帧率保证；用户原始长文与多屏 DPI 仍需验收。

## Vellum 调研

核对的是用户指定的 [HwFee/vellum](https://github.com/HwFee/vellum)，master `e868782911e59b9d05683f49eff26ea776479f71`，不是搜索结果里的其他同名编辑器。

- [设计语言](https://github.com/HwFee/vellum/blob/master/DESIGN.md)：阅读层级主要由字号、留白和明度差承担，控件应安静。这适合 Mica 的阅读优先定位，不需要照搬字体、品牌或整套主题。
- [CustomScrollbar](https://github.com/HwFee/vellum/blob/master/src/components/CustomScrollbar.tsx)：独立滑块与拖动接管事件，避免恢复位置逻辑抢回滚动。这次借鉴交互原则，在 Mica 中重新实现 pointer capture 和连续比例映射，并处理编辑器虚拟化时高度变化。
- [editorGeometry](https://github.com/HwFee/vellum/blob/master/src/lib/editorGeometry.ts)：强调坐标系必须来自真实宿主几何。Mica 问题不同，实际根因是字体改变后高度缓存未失效，因此保留 CodeMirror，通过公开 API 修复。
- Vellum 是 React/Tauri 的阅读器与块编辑，Mica 是 WPF/WebView2 + CodeMirror；本次没有引入它的依赖、执行它的代码或迁移技术栈，也未复制其源码。

仅修改本地，未提交或推送远程仓库。
