# 编辑交互与隔离绘图 · 0.7.1

## 编辑流程

1. 选区背景使用应用主题，不再被 CodeMirror 默认浅色主题覆盖。
2. 区分“活动编辑位置”与“选中范围”。鼠标拖选和非空选区保持预览状态；不会因为选中了代码/表格/公式，就把这些块全部展开成源码。
3. 选择变化查找已建立的块索引，只更新前后活动块。相同行内移动和拖选不重建行内装饰；视口改变仍按需更新。文档或解析树变化时仍重建块索引，未宣称任意编辑都是常数时间。
4. 输入仅向 WPF 发送小型 dirty 通知，不再在每次输入中执行全文 sliceDoc/序列化/跨端传输。实时文字由 WebView 编辑器持有，保存、另存、切换文件/模式、关闭前获取完整快照。保留显式保存和草稿提醒。
5. 中文 composition 期间固定活动区域；未确认组词时拒绝结束编辑/保存，不取旧内容覆盖。自动化验证为合成 composition 生命周期，不替代 Windows 中文输入法实际候选框验证。
6. 编辑中的图表预览延迟 300 ms 启动；预览节点销毁时取消排队或运行中的隔离任务，避免刚离开就继续绘图。

## 隔离绘图

- 入口：**··· → 隔离绘图：关闭/开启（实验）**。仅本窗口有效，默认关闭；图表独立窗口继承来源引擎。开启后阅读与实时编辑均使用 Worker 绘图。
- 固定使用实验验证的 `@mermanjs/web-render@0.8.0-alpha.7`，离线打包，首次使用才创建 Worker 和载入 WASM；新增约 10.6 MiB WASM，不能说没有体积代价。
- Worker 串行绘图，等待队列最多 16 项；源码 100,000 字符上限，SVG 4,000,000 字符上限，保持 interactive 资源保护。
- 每项运行包含初始化的父线程截止时间为 8 秒。超时/活动任务取消时 terminate Worker；后续请求可重建。切换文档、主题或绘图引擎取消过期任务；闲置 Worker 可复用。
- 采用 resvg-safe 输出保留 ER/思维导图文字；主页面仍用 DOMPurify 清理 SVG，禁用 script/foreignObject。CSP 只增加 wasm-unsafe-eval，不允许普通 eval、外部脚本或文档内脚本。
- 不支持、资源超限或超时均可重试；阅读页面提供 **兼容绘图（可能短暂卡顿）**，由用户明确选择。不会自动回退到主线程并把阻塞隐藏起来。
- 兼容 Mermaid 路径仍在页面线程。排队任务可丢弃，但已经开始的同步计算不能硬中断。该限制没有被 Worker 实验消除。

## 本机验证

`tests/live-editor.mjs`：四主题选区色、真实鼠标跨块拖选、预览 DOM 身份不变、非空选择不展开块、中文文本/合成 composition、撤销重做、CRLF、保存快照、长文按视口挂载。129,780 字符合成文档中，连续 200 次选择变化没有增加块扫描/行内装饰重建次数；一轮总调度约 56 ms，单次 P95 约 0.5 ms。该值是同步事务时间，不是端到端输入延迟或显示器 FPS。

`tests/diagram-client.test.mjs`：排队、超时终止、恢复、活动/排队取消、过期回复隔离、输入/输出上限。

`tests/isolated-diagrams.mjs`：8 种有效样本和错误样本、四主题截图、SVG 清理、独立窗口参数、资源拒绝后不自动回退、手动兼容绘图、文档切换取消和离线请求。测试服务器单独提供忙循环 Worker，生产包不含故障注入入口：150 ms 超时约 151 ms 终止，期间 10 ms 心跳运行 15 次，下一次请求恢复成功。

原生 UiSmoke：真实 WebView2 加载 WASM、中文图表、全屏/独立窗口继承隔离模式、笔记、最后输入保存、跨文档草稿、原有阅读功能。以上仍不等同于覆盖所有 Mermaid 类型、真实巨型文档、多显示器 DPI 或 Windows 输入法。

Sätteri 替换解析器和全量富文本编辑器迁移均未实施。本轮没有改动远程仓库。
