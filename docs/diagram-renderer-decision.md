# Mica 图表渲染决策 · 2026-10-02

## 已采用

- 默认使用 **Merman Worker + ELK + Neo**。图表解析和排版不占用阅读页面主线程。
- Mermaid 12 作为显式兼容路径。现代引擎失败时显示“兼容绘图”，不自动回退并造成无提示卡顿。
- 行内预览固定高度并延迟绘制；小图不放大，大图才缩小适配。
- 统一 Viewer 支持适应窗口、适应宽度、实际大小、鼠标中心缩放、拖动平移、全屏和独立窗口。
- 用户手动缩放或平移后，窗口尺寸变化不再重置视点。

## 没有采用 Zombie Mermaid 的原因

Zombie Mermaid 3.2 的包目标是 Node.js 22+。其同步 ELK 路径依赖 CommonJS FakeWorker；在浏览器/WebView 的 module Worker 中打包后无法可靠构造内部 Worker。实验中兼容回退正常，但增强路径本身失败，因此没有把“能回退”误算为可用集成，也没有留下约 1.6 MiB 的额外 ELK 包。

它的视觉和 parser → IR → layout → SVG 分层仍值得作为长期架构参考；若以后自建 Mica SVG renderer，应单独做真实语料覆盖率与视觉回归，而不是在正式阅读链路中试错。

## 验收边界

- Worker 有超时、终止、重建、取消和队列限制。
- SVG 插入前经过清理，不允许脚本、事件属性和 `foreignObject`。
- 四套主题分别验证标签可见性。
- 长文档继续采用分批挂载与屏幕外跳过排版；图表只在接近视口时绘制。
